# @premai/reticle

Hardware attestation SDK that cryptographically verifies AMD SEV-SNP, Intel TDX, and NVIDIA GPU enclaves. Runs in Node.js, Bun, Deno, Bare and browsers via WebAssembly.

- **npm:** `@premai/reticle`
- **GitHub:** https://github.com/prem-research/reticle
- **npm:** https://www.npmjs.com/package/@premai/reticle
- **Attestation server** (REST, auto-detects available hardware): separate binary — `attestation-server`

## Installation

```bash
npm install @premai/reticle
```
